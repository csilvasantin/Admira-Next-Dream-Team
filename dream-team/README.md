# Dream Team

Esta carpeta organiza las estrellas del `Admira Next Dream Team`.

Cada subcarpeta representa un asistente o IA con la que podemos colaborar dentro del proyecto. La idea es que cada una tenga:

- un rol claro,
- un tipo de aportacion reconocible,
- contexto rapido de lectura,
- y espacio para evolucionar su forma de trabajo.

## Estrellas iniciales

- `claude`
- `codex`
- `gemini`
- `perplexity`
- `mistral`
- `customer-care`

## Objetivo de esta estructura

Preparar el repositorio para una colaboracion organizada entre varias IAs, evitando mezclar sus perfiles, responsabilidades y notas de trabajo.

## Como leer los roles

Cada estrella del equipo debe quedar definida con estos bloques:

1. mision dentro del proyecto,
2. fortalezas principales,
3. tareas que deberia liderar,
4. limites o riesgos de uso,
5. y forma de coordinacion con el resto.

## Mapa rapido del equipo

- `claude`: claridad, estructura y narrativa.
- `codex`: ejecucion, implementacion y orden tecnico.
- `gemini`: exploracion, comparacion y apertura de opciones.
- `perplexity`: investigacion, contraste y referencias externas.
- `mistral`: velocidad, simplificacion e iteracion ligera.
- `customer-care`: voz del cliente, experiencia y continuidad relacional.

## Proximo paso recomendado

Definir para cada estrella:

1. su rol principal,
2. que tipo de tareas debe liderar,
3. que tono o criterio aporta al equipo,
4. y como se coordina con las demas.
