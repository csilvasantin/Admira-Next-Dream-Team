# Proyecto 05 — Admira-Next-Dream-Team

Este repositorio se llama `Admira Next Dream Team`.

## Estado actual

- El proyecto esta en fase inicial.
- Todavia no hay stack tecnico cerrado.
- La prioridad es ayudar a definir estructura, alcance y primeros entregables.

## Como colaborar aqui

- Lee primero `README.md` y `AI_COLLABORATION.md`.
- Haz cambios pequenos, claros y faciles de revisar.
- No introduzcas dependencias ni tooling sin justificarlo.
- Si el objetivo no esta definido, propone una estructura simple antes de construir mucho codigo.

## Principios del proyecto

- Claridad antes que complejidad.
- Velocidad de iteracion.
- Base limpia para que varios asistentes puedan colaborar.
- Documentar decisiones importantes segun aparezcan.

## Primeras tareas recomendadas

1. Proponer estructura inicial del proyecto.
2. Elegir stack.
3. Crear una primera version visible del producto o concepto.
