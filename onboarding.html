Onboarding

Admira Next Dream Team

Esta pagina resume el contexto del proyecto para cualquier persona que quiera entenderlo rapido. En paralelo, existe una version en Markdown para que otras IAs puedan leer el mismo contenido de forma mas operativa.

Vision

Que estamos haciendo

Estamos montando una base de proyecto pensada para colaboracion entre varias IAs y humanos. Antes de entrar en una implementacion tecnica grande, estamos definiendo contexto, reglas de trabajo y una estructura comun.

El objetivo de esta fase es construir claridad compartida. La tecnologia llegara despues, cuando la direccion del proyecto este mejor decidida.

Estado actual

Donde estamos

  • Repositorio en fase inicial.
  • Sin stack tecnico definitivo.
  • Sin producto implementado aun.
  • Con documentacion base para colaboracion entre asistentes.
  • El onboarding es el primer punto de lectura antes de cada actualizacion.
Prioridad

Que importa ahora

  • Ordenar contexto.
  • Facilitar continuidad entre sesiones.
  • Evitar trabajo duplicado entre IAs.
  • Preparar una primera direccion clara del proyecto.
Conceptos

Los conceptos que estamos trabajando

Colaboracion multi-IA

Definir una forma de trabajo donde varias IAs puedan aportar sin pisarse ni perder contexto.

Contexto persistente

Dejar documentado que es el proyecto, en que fase esta y que reglas deben respetarse al colaborar.

Claridad antes que complejidad

No elegir arquitectura ni dependencias grandes hasta entender bien el tipo de producto que queremos construir.

Formato dual

Una version para IAs y otra para humanos

Este proyecto usa dos formatos de conocimiento:

  • Markdown para lectura tecnica y colaboracion operativa.
  • HTML para lectura humana mas comoda, visual y rapida.
Principios

Como queremos construir

  • Cambios pequenos y revisables.
  • Documentacion como infraestructura.
  • Repositorio ligero en la fase inicial.
  • Continuidad entre asistentes y sesiones.
  • Revisar siempre el onboarding antes de ponerse a trabajar.
Regla diaria

Lo primero que hay que mirar

Antes de cada actualizacion y antes de empezar cualquier dia de trabajo en el Dream Team de Admira Next, el primer archivo que debe revisarse es el onboarding.

Esto asegura que si otra IA ha dejado consejos, novedades, contexto nuevo o cambios de direccion, todo el equipo empiece desde la version mas actualizada del proyecto.

Entrada recomendada

Como deberia incorporarse una nueva IA

  1. Leer `ONBOARDING.md` como primer paso obligatorio.
  2. Leer el `README.md`.
  3. Leer `AI_COLLABORATION.md`.
  4. Revisar `CLAUDE.md` si necesita instrucciones especificas.
  5. Confirmar el objetivo actual antes de editar el repo.

Resumen

`Admira Next Dream Team` esta creando una base clara para que varias IAs y personas puedan colaborar con continuidad. La fase actual no busca escalar tecnologia, sino ordenar la inteligencia del proyecto antes de construir.
