# Admira Next Dream Team

Repositorio base para `Admira Next Dream Team`, preparado para colaborar con asistentes de IA desde el inicio.

## Archivos clave

- `index.html`: web principal del Dream Team.
- `README.md`: vision general del repositorio.
- `.gitignore`: exclusiones comunes para desarrollo.
- `CLAUDE.md`: contexto e instrucciones iniciales para Claude.
- `AI_COLLABORATION.md`: normas compartidas para trabajar con distintas IAs.
- `ONBOARDING.md`: onboarding central para asistentes y colaboradores.
- `INSTRUCCIONES.md`: reglas de trabajo y entrega visible durante el proceso.
- `OFFBOARDING.md`: cierre diario y transferencia de contexto.
- `onboarding.html`: version HTML del onboarding para lectura humana.
- `dream-team/`: estructura de subcarpetas por cada estrella del equipo.

## Objetivo inicial

Crear una base clara para que varias IAs puedan entrar en el proyecto, entender el contexto rapido y colaborar sin pisarse.

## Estrategia organizativa

Admira Next quiere seguir una estrategia de convertirse en una `organizacion Pulpo`, con 8 extremidades directivas que concentran los roles mas potentes de un consejo de direccion o administracion.

Los 8 roles definidos por ahora son:

1. `CEO`
2. `CFO`
3. `CTO`
4. `CMO`
5. `COO`
6. `CHRO`
7. `CLO`
8. `CSO`

En este esquema:

- `CEO`: vision, direccion general y alineacion del conjunto.
- `CFO`: capital, eficiencia y disciplina financiera.
- `CTO`: tecnologia, automatizacion y arquitectura.
- `CMO`: marca, crecimiento y mercado.
- `COO`: operaciones y ejecucion.
- `CHRO`: talento, cultura y universidad corporativa.
- `CLO`: regulacion, compliance y marco juridico.
- `CSO`: estrategia, internacionalizacion y movimientos de largo plazo.

## Marco estrategico de Admira Next

Los retos principales que Admira Next quiere ayudar a salvar son:

1. escasez de trabajadores,
2. restricciones de capital,
3. energia, infraestructuras y regulacion.

### Respuesta conocida al reto 1

Para el reto de la escasez de trabajadores, la solucion de Admira ha sido la creacion de su propia Universidad.

### Respuesta conocida al reto 2

Para el reto de las restricciones de capital, la solucion de Admira es `Admira Next`: innovacion con soluciones mas automatizadas que permiten hacer mas con los mismos recursos.

### Respuesta conocida al reto 3

Para el reto de la energia, las infraestructuras y la regulacion, la solucion activada es la internacionalizacion con foco en China.

## Regla de entrada

Antes de cada actualizacion y al inicio de cada dia de trabajo, el primer documento que debe leerse es `ONBOARDING.md`.

## Regla de salida

Al cerrar cada jornada de trabajo, debe completarse el offboarding y actualizar la web principal del proyecto.

Ademas, durante el trabajo debe respetarse `INSTRUCCIONES.md`, que fija como obligatoria la secuencia HTML -> Pages -> limpieza de cache -> apertura de URL publica.

Despues de ese cierre, la pagina web resultante debe abrirse desde la URL publica para revision visual.
